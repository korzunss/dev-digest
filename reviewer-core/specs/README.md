# reviewer-core/specs — feature specifications for the review engine

Specs for work contained in the engine. Anything spanning several packages goes
in the repo-root [`specs/`](../../specs/README.md), which also carries the naming
rules and the template.

**Read the spec before implementing the feature.** In this package that matters
more than elsewhere: a change to prompt assembly or the grounding gate changes
every review the product produces.

Written by the `spec-creator` agent. Numbering and the template are repo-wide, in
[`specs/README.md`](../../specs/README.md). The `Status:` line is
`draft | approved | implemented`.
